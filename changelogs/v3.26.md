# v3.26.0 (2026-02-13)

## ralph-loop 통합 + auto-recovery: plan/execute 스킬 자동화 대폭 개선

### Added

- **wf:plan 스킬 - ralph-loop 통합 (Graceful Degradation)**
  - Phase 3에 ralph-loop 우선 시도 로직 추가
  - ralph-loop 사용 가능 시: 완전 자동화된 반복 검토 루프
  - ralph-loop 미사용 시: built-in review loop로 자동 fallback
  - 호출 방식: `Skill(ralph-loop:ralph-loop)` 형식

- **wf:execute 스킬 - 자동 복구 루프 (Auto-Recovery Loop)**
  - Phase 8에 테스트 및 검증 실패 시 자동 복구 메커니즘 추가
  - 8가지 실패 타입 자동 분류 및 처리:
    1. IMPLEMENTATION_BUG: 코드 수정
    2. PLAN_DESIGN_FLAW: plan 재작성 → execute 재실행
    3. SUCCESS_CRITERIA_UNMET: 코드 수정 or 기준 재검토
    4. CODE_STANDARDS_VIOLATION: 자동 포맷팅
    5. PERFORMANCE_ISSUE: 최적화 or 재설계
    6. SECURITY_ISSUE: 보안 패치
    7. REGRESSION: 회귀 수정
    8. ENVIRONMENT_ISSUE: 사용자 개입
  - 최대 3회 자동 재시도
  - 테스트 실패 뿐 아니라 모든 verification 항목 커버

- **README.md - ralph-loop 권장 플러그인 섹션 추가**
  - `~/.claude/settings.json` 설정 방법 안내
  - ralph-loop 활성화 시 효과 명시
  - 권장 대상 설명

- **CLAUDE.md - Optional Dependency 설명 추가**
  - ralph-loop 의존성 문서화
  - With/Without ralph-loop 동작 차이 설명
  - 활성화 방법 및 호출 방식 안내
