# v3.18.0 문서화 가이드라인 (2026-02-04)

## Language Convention

SKILL.md 및 Agent 문서 작성 시 언어 규칙:

| 요소 | 언어 | 예시 |
|------|------|------|
| 지시어/Directives | 영어 | "Gather all relevant information" |
| 섹션 헤더 | 영어 | "## Phase 1: Context Collection" |
| 예시/Samples | 한국어 | "분석 대상: `src/auth/login.ts`" |
| 코드 주석 | 영어 | `// Check branch protection` |

## Slack MCP 핵심 규칙

멘션이 동작하려면 **반드시** `content_type: text/plain` 사용:

```python
mcp__plugin_slack_slack__conversations_add_message(
    channel_id="CHANNEL_ID",
    payload="<@USER_ID> 메시지",
    content_type="text/plain"  # 필수!
)
```

**주의**: `text/markdown` 사용 시 `<@USER_ID>` 형식이 escape되어 멘션 안됨.

## Interactive Branch Validation

Phase 0에서 AskUserQuestion을 사용하여 사용자가 직접 선택:
1. 새 브랜치 생성 (권장)
2. 현재 브랜치에서 계속 (비권장)

기존: 자동 브랜치 생성 → 변경: 사용자 확인 후 생성
