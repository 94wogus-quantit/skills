# v3.17.0 - Plugin/MCP 이름 단축 (2026-01-29)

## 배경

Claude API의 tool name 64자 제한(`tool_reference.tool_name: String should have at most 64 characters`)으로 인해
MCP 도구 호출 시 `invalid_request_error`가 발생하는 문제 해결.

도구 이름 자동 생성 패턴: `mcp__plugin_<PLUGIN_NAME>_<SERVER_NAME>__<TOOL_NAME>`

## Breaking Changes ⚠️

기존 설치 사용자는 플러그인을 재설치해야 합니다:

```bash
# 기존 플러그인 제거
/plugin uninstall wogus-plugins:workflow-bundle
/plugin uninstall wogus-plugins:sequential-thinking
/plugin uninstall wogus-plugins:gitlab-mr

# 새 이름으로 재설치
/plugin install wogus-plugins:wf
/plugin install wogus-plugins:seq-think
/plugin install wogus-plugins:glmr
```

`~/.claude/settings.json`의 permissions도 업데이트 필요:
- `Skill(workflow-bundle:*)` → `Skill(wf:*)`
- `mcp__plugin_workflow-bundle_git-local__*` → `mcp__plugin_wf_git__*`
- `mcp__plugin_sequential-thinking_sequential-thinking__*` → `mcp__plugin_seq-think_st__*`
- `mcp__plugin_gitlab-mr_gitlab-ci__*` → `mcp__plugin_glmr_ci__*` (신규 추가)
- `enabledPlugins` 키도 동일하게 변경
