# v3.27.0 - ask-yt 플러그인: YouTube AI CDP 자동화

**날짜**: 2026-02-19
**브랜치**: `feature/ask-youtube`

---

## 요약

YouTube 내장 AI "질문하기(Ask)" 기능을 CDP(Playwright) 기반으로 자동화하는 `ask-yt` 플러그인을 신규 추가합니다. URL + 질문을 입력하면 YouTube Gemini AI의 응답을 자동으로 반환합니다.

---

## Added

- **`plugins/ask-yt/`** 신규 플러그인 추가
  - `youtube_ask_server.py`: Python Playwright 기반 FastMCP 서버 (3개 도구)
    - `open_ask_panel(url, cdp_port, timeout_ms)`: YouTube 영상 페이지로 이동 후 Ask 패널 열기
    - `ask_video(question, timeout_ms)`: 열린 패널에서 YouTube AI에게 질문 (멀티턴 지원)
    - `close_session()`: Playwright 세션 종료
  - `skills/ask-yt/SKILL.md`: 4개 Phase + **Phase 0 Chrome CDP 설정 가이드** 포함
    - Chrome 프로필 복사 → CDP 모드 실행 → YouTube 로그인 확인 전체 DX 가이드
    - 5가지 공통 에러 및 해결 방법 표
  - `.claude-plugin/plugin.json`: 플러그인 메타데이터
  - `.mcp.json`: uvx 기반 MCP 서버 설정 (`--with playwright` 필수)
  - `README.md`: 설치 및 Chrome CDP 설정 가이드

- **`.claude-plugin/marketplace.json`**: `ask-yt` 플러그인 등록 (9번째 플러그인)

## 기술적 결정사항

### 멀티턴 설계 (Stateful MCP Server)

**결정**: `ask_video(url, question)` 단일 함수 대신 `open_ask_panel` + `ask_video` + `close_session` 3개로 분리.

**이유**: 동일 영상에 대해 여러 질문 시 매번 패널을 열면 비효율적. 글로벌 `_pw`/`_page` 상태로 세션을 유지하여 연속 질문 지원.

### YouTube Trusted Types CSP 우회

**문제**: `page.wait_for_function(JS_STRING)` → `EvalError: Evaluating a string as JavaScript violates this document's Trusted Type assignment requirements`

**해결**: JS 문자열 평가 대신 Python 폴링 루프 사용:
```python
deadline = time.time() + timeout_ms / 1000
while time.time() < deadline:
    if len(page.query_selector_all('markdown-div')) > initial_md_count:
        break
    time.sleep(0.5)
```

### Polymer 이벤트 이슈

**문제**: `fill()` 함수가 YouTube Polymer 웹 컴포넌트의 이벤트를 트리거하지 않음 → 전송 버튼이 항상 `aria-disabled="true"` 유지.

**해결**: `keyboard.type(question, delay=30)` + `keyboard.press('Enter')` 패턴으로 대체.

### Chrome CDP 비기본 user-data-dir 요구사항

**문제**: `--remote-debugging-port` 플래그는 Chrome 기본 데이터 디렉토리(`~/Library/Application Support/Google/Chrome`)에서 실행 시 차단됨.

**해결**: 기존 Chrome 프로필을 `Chrome-CDP/` 디렉토리로 복사하여 로그인 세션을 유지하면서 비기본 경로 사용.

### AI 응답 완성 신호

**결정**: `markdown-div` 카운트 증가 + `button.ytwYouChatChipsDataChip` 카운트 증가를 스트리밍 완성 신호로 사용.

**이유**: `data-target-id^="youchat-"` 패턴으로 실제 AI 응답과 환영 메시지를 구분하려 했으나, Trusted Types CSP로 인해 `wait_for_function` 불가. 대신 `markdown-div` 전체 카운트와 chips 카운트 증가로 판단.

## 알려진 제한사항

- **로그인 필수**: YouTube Ask는 로그인된 계정에서만 노출
- **라이브 스트림/일부 영상 미지원**: Ask 버튼이 없는 영상은 `ValueError` 발생
- **Chrome CDP 설정 복잡도**: 처음 사용 시 Phase 0 Chrome 설정 필요 (1회성)
- **다국어 aria-label**: `질문하기` (한국어), `Ask` (영어) 동시 지원 셀렉터 사용
