# v3.22.0 - plan 스킬 업그레이드: 5단계 알고리즘 통합 (2026-01-30)

## 변경 요약

plan 스킬의 Phase 2(Initial Plan Creation)에 일론 머스크 5단계 알고리즘을 핵심 사고 방법론으로 통합하고, Idiot Index 효율성 메트릭과 Zero-Context Plan Writing 원칙을 도입.

## Added

### planning_mental_model.md (신규 레퍼런스, 228줄)

- **5단계 알고리즘 가이드**: 요구사항 질의 → 삭제 → 단순화 → 가속 → 자동화 (엄격한 순서)
- **Idiot Index**: 계획 효율성 메트릭 (전체 노력 / 핵심 기능 노력)
  - 임계값: 1-2x ✅ 효율적, 2-3x ⚠️ 주의, 3-5x 🔴 삭제 패스 재실행, 5x+ ⛔ 근본 재설계
- **Zero-Context Plan Writing**: obra/superpowers 참고, 정확한 파일 경로·코드 스니펫·실행 가능한 테스트 커맨드 필수
- **Anti-Patterns**: 삭제 전 최적화, 무명 요구사항, 조기 자동화, 안전지대 스코프, 템플릿 비대화

### review_checklist.md - Section 11 추가

- **효율성 & 필요성 평가 섹션**: Idiot Index 평가, 삭제 체크, 과잉 설계 탐지
- 체크리스트 범위 1-10 → 1-11로 확장
- Review Output Template에 Section 11 반영

## Changed

  6. Acceleration Analysis (머스크 Step 4)
