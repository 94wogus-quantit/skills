# v3.15.0 - git-local MCP 확장

**릴리스 날짜**: 2026-01-17

## 개요

git-local MCP 서버에 자주 사용하는 git 작업 도구 7개를 추가하여 워크플로우 스킬과의 통합성을 높이고 Bash 호출을 줄임.

## Added

### Git 작업 도구 (7개 신규)

- **git_status()**: Git 저장소의 파일 상태 반환
  - staged, modified, untracked, deleted 파일 분류
  - `--porcelain` 형식 파싱으로 안정적인 출력

- **git_log(count)**: 최근 커밋 히스토리 조회
  - NULL 문자 구분자 사용 (커밋 메시지 내 특수문자 대응)
  - hash, message, author, date 반환

- **git_add(files)**: 파일 스테이징
  - 단일 파일 또는 "." (전체) 지원
  - 스테이징된 파일 목록 반환

- **git_commit(message)**: 커밋 생성
  - 메시지 검증 (빈 메시지 방지)
  - 스테이징된 파일 확인 후 커밋
  - 짧은 커밋 해시 반환

- **git_diff(staged)**: 변경 내용 통계
  - staged 옵션으로 스테이징 영역 diff 지원
  - files_changed, insertions, deletions 통계

- **git_push(branch, set_upstream, force)**: 원격 저장소 푸시
  - -u 플래그 옵션 지원
  - --force 옵션 지원 (보호 브랜치 제외)
  - 현재 브랜치 자동 감지

- **git_squash(commit_count, message)**: 커밋 squash
  - 최근 N개 커밋을 하나로 합치기
  - 커밋 메시지 지정 가능 (기본: 첫 번째 커밋 메시지)

## Technical Details

### 구현 방식
- **subprocess 유지**: 기존 코드와 일관성을 위해 subprocess 사용 (GitPython 미사용)
- **run_git_command() 헬퍼**: 모든 git 명령에 공통 헬퍼 함수 사용
- **일관된 응답 형식**: `{success, message, ...}` 패턴

### 특이사항
- **git_log NULL 구분자**: 커밋 메시지에 `|` 포함 가능성 대비하여 `%x00` (NULL) 사용
- **git_commit 메시지 검증**: `.strip()` 후 빈 문자열 체크

## 도구 목록 (전체)

### 브랜치 관리 (기존)
1. `get_current_branch` - 현재 브랜치 이름 반환
2. `check_branch_protection` - 보호된 브랜치 여부 확인
3. `create_feature_branch` - 새 feature 브랜치 생성
4. `list_branches` - 모든 브랜치 목록 조회
5. `switch_branch` - 브랜치 전환

### Git 작업 (신규)
6. `git_status` - 파일 상태 확인
7. `git_log` - 커밋 히스토리 조회
8. `git_add` - 파일 스테이징
9. `git_commit` - 커밋 생성
10. `git_diff` - 변경 내용 통계
11. `git_push` - 원격 저장소 푸시 (force 옵션)
12. `git_squash` - 커밋 squash
