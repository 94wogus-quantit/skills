# v3.13.0 - 2026-01-05

## GitLab CI/CD 관리 기능 추가

gitlab-mr 플러그인에 CI/CD 파이프라인 관리를 위한 4개 스킬 추가.

### Added

- **gitlab-mr 플러그인 CI/CD 스킬 추가** (v1.2.0)
  - `ci-status` 스킬: 파이프라인 상태 조회 + 에러 로그 분석 (sequential-thinking 활용)
  - `ci-retry` 스킬: 실패한 job 재실행 (단일/전체 지원)
  - `ci-trigger` 스킬: Manual job 트리거 + 새 파이프라인 실행
  - `ci-cancel` 스킬: 파이프라인/job 중지

### Changed

- **gitlab-mr 플러그인 확장**
  - 3 skills → 7 skills (MR 관리 3개 + CI/CD 4개)
  - 설명 업데이트: "GitLab MR and CI/CD management"

### Technical Details

**CI/CD 스킬 Korean Triggers**:

| 스킬 | Triggers |
|------|----------|
| ci-status | CI 상태, 파이프라인 상태, CI 확인, job 실패, CI 로그 |
| ci-retry | CI 재실행, 파이프라인 재시도, 다시 돌려 |
| ci-trigger | CI 실행, 파이프라인 실행, 수동 실행 |
| ci-cancel | CI 중지, 파이프라인 취소, CI 멈춰 |

**glab CLI 명령어 매핑**:

| 스킬 | glab 명령어 |
|------|-------------|
| ci-status | `glab ci status`, `glab ci list`, `glab ci trace` |
| ci-retry | `glab ci retry` |
| ci-trigger | `glab ci trigger`, `glab ci run` |
| ci-cancel | `glab ci cancel` |

**플러그인 구조**:
```
plugins/gitlab-mr/ (v1.2.0)
├── .claude-plugin/plugin.json
└── skills/
    ├── mr-review/         # MR 코드 리뷰
    ├── list-discussions/  # discussion 목록
    ├── fix-discussion/    # discussion 수정
    ├── ci-status/         # CI 상태 + 에러 분석 ✨
    ├── ci-retry/          # CI 재실행 ✨
    ├── ci-trigger/        # CI 트리거 ✨
    └── ci-cancel/         # CI 중지 ✨
```

**사용 예시**:
```
"현재 브랜치 CI 상태 확인해줘"
"실패한 job 다시 돌려줘"
"배포 job 수동 실행해줘"
"CI 중지해줘"
```
