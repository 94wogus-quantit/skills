# v3.12.0 - 2026-01-05

## GitLab MR 플러그인 신규 & Sequential Thinking 분리

GitLab MR 관리를 위한 전용 플러그인 추가 및 sequential-thinking MCP 독립 플러그인으로 분리.

### Added

- **gitlab-mr 플러그인 신규**
  - `mr-review` 스킬: workflow-bundle에서 이동 (MR 코드 리뷰)
  - `list-discussions` 스킬: MR의 unresolved discussion 목록 조회
  - `fix-discussion` 스킬: discussion 수정 및 resolve 처리
  - sequential-thinking MCP 포함

- **sequential-thinking 플러그인 신규**
  - workflow-bundle에서 분리하여 독립 플러그인으로 제공
  - 체계적인 단계별 사고를 위한 MCP 서버

### Changed

- **workflow-bundle 경량화**
  - mr-review 스킬 → gitlab-mr 플러그인으로 이동
  - sequential-thinking MCP → 별도 플러그인으로 분리
  - 4 skills + agent 구성 (analyze, plan, execute, record)

- **marketplace 플러그인 구성 변경**
  - 6개 → 7개 플러그인: workflow-bundle, **gitlab-mr**, **sequential-thinking**, terraform, amplitude, slack, atlassian

### Technical Details

**새로운 플러그인 구조**:
```
plugins/
├── workflow-bundle/       # 4 skills + agent (MCP 미포함)
├── gitlab-mr/             # 3 skills + sequential-thinking MCP
│   ├── skills/
│   │   ├── mr-review/
│   │   ├── list-discussions/
│   │   └── fix-discussion/
│   └── .mcp.json
├── sequential-thinking/   # MCP만 포함
│   └── .mcp.json
├── terraform/
├── amplitude/
├── slack/
└── atlassian/
```

**설치 명령어**:
```bash
/plugin install wogus-plugins:workflow-bundle       # 4 skills + agent
/plugin install wogus-plugins:gitlab-mr             # GitLab MR 관리
/plugin install wogus-plugins:sequential-thinking   # Sequential Thinking MCP
```
