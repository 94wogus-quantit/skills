# v3.14.0 - GitHub MCP 플러그인 추가

**릴리스 날짜**: 2026-01-12

## 개요

GitHub MCP 플러그인을 추가하여 저장소, 이슈, PR 관리 기능을 지원합니다.

## 변경사항

### Added

- **GitHub MCP 플러그인** (`plugins/github/`)
  - GitHub 저장소 관리
  - 이슈 생성/조회/수정
  - Pull Request 관리
  - `@modelcontextprotocol/server-github` 패키지 사용

### 환경 변수

```bash
# GitHub Personal Access Token
export GITHUB_TOKEN="ghp_your-personal-access-token-here"
```

### 설치

```bash
/plugin install wogus-plugins:github
```
